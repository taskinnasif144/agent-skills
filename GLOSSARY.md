# agent-skills

Installable agent skills for the skills.sh ecosystem and opencode. One name per concept: docs, README text, and skill descriptions use these terms only.

## Language

**Skill**:
A SKILL.md file that gives an agent instructions for one task. The folder name is the skill ID.
_Avoid_: prompt, playbook

**Slash command**:
An entry in the `/` menu that routes to a skill. It comes from a command file, not from a skill file.
_Avoid_: slash skill, command skill

**Flash pass**:
A research run at quick speed, done by the flash-research skill. The answer is 250 to 400 words.
_Avoid_: quick research, light research

**Full treatment**:
A research run at deep speed, done by the verified-research skill. The answer is 600 to 800 words.
_Avoid_: deep research, full research

**High-stakes decision**:
A decision about careers, money, or long-term commitments. It always gets the full treatment.
_Avoid_: important question, big decision

**Targeted search**:
A lightweight research run of the targeted-search skill: one light interview round, three angle-searchers, a 150 to 300 word chat summary.
_Avoid_: quick search, web search
